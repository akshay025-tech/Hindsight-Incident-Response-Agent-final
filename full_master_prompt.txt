1. HACKATHON PROBLEM
============================================================

Selected problem:

ENGINEERING & DEVOPS AGENT

INCIDENT RESPONSE AGENT

Business Case:

"Incident Response Agent remembers past incidents, their root
causes, resolution steps, and which runbooks worked. Learns from
post-mortems to suggest faster fixes for similar issues."

This exact idea must drive the architecture.

The application must demonstrate that the system:

1. Receives an incident.
2. Investigates it.
3. Uses Hindsight to recall similar historical incidents.
4. Uses an LLM to reason about the current incident.
5. Identifies possible root causes.
6. Finds relevant runbooks.
7. Recommends a response.
8. Keeps a human in the loop.
9. Resolves the incident.
10. Generates a postmortem.
11. Retains useful learning into Hindsight.
12. Uses that learning during a future similar incident.

THE MOST IMPORTANT DEMONSTRATION:

FIRST INCIDENT
    ↓
INVESTIGATE
    ↓
RESOLVE
    ↓
POSTMORTEM
    ↓
HINDSIGHT RETAIN
    ↓
SECOND SIMILAR INCIDENT
    ↓
HINDSIGHT RECALL
    ↓
PREVIOUS ROOT CAUSE + RESOLUTION + RUNBOOK
    ↓
FASTER RECOMMENDATION

If this learning loop does not work, the project is not complete.
